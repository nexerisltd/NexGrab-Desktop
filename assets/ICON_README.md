# App icon

Drop your NexGrab logo here in three formats (convert at https://cloudconvert.com/png-to-icns
or https://icoconvert.com — upload one 512x512+ PNG and it generates all three):

- icon.png    (Linux + in-app header logo)
- icon.ico    (Windows)
- icon.icns   (macOS)

main.js and package.json already reference these exact filenames — nothing
else to configure once they're here.
